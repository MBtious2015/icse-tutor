# ICSE AI Tutor - Class 6

**A complete AI-powered learning platform for ICSE Class 6 students at DPS Megacity Kolkata**

## What's Included

- **icse-tutor.html** - Main application (fully self-contained)
- **vercel.json** - Vercel configuration
- **DEPLOYMENT_GUIDE.md** - Complete setup instructions

## Quick Deploy (30 seconds)

1. Go to [vercel.com](https://vercel.com)
2. Sign up or login
3. Go to [vercel.com/new](https://vercel.com/new)
4. Drag `icse-tutor.html` into the deploy area
5. Done! 🎉

Your app will be live at: `https://your-project-name.vercel.app`

## Features

✅ **8 ICSE Subjects** - Math, Physics, Chemistry, Biology, English, History, Civics, Geography

✅ **3 Learning Modes** - Learn, Practice, Test

✅ **Student Accounts** - Each student has their own login & progress tracking

✅ **AI-Powered** - Uses Claude to generate personalized explanations and problems

✅ **Works Everywhere** - Mac, Windows, iPhone, iPad, Android (any browser)

✅ **Completely Free** - No credit card needed
